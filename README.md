# login-form-with-only-html-css-just-front-end
Modern Login Form UI -  A clean, modern, and responsive login form designed using only HTML and CSS.
This project features a minimalist layout, stylish input fields, a password field, a login button, and a user-friendly interface. The design focuses on simplicity, visual appeal, and a smooth user experience.

**Technologies:** HTML5, CSS3

**Features:**

* Modern and minimalist design
* Responsive layout
* Styled input fields
* Clean typography and spacing
* No JavaScript or backend functionality
